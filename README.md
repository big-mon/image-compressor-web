# image-compressor-web

ブラウザ内で画像をトリミング・圧縮する、独立した静的 React + TypeScript + Vite アプリです。

## Quick Start

```sh
pnpm install --frozen-lockfile
pnpm run dev
```

## 機能とスコープ

JPEG・PNG・WebPを選択し、ズーム・パン・比率指定付きのクロップ、90度回転、±45度の傾き補正、反転、リサイズ、形式・品質指定、Worker生成のクイックプレビュー、出力設定を開いている間の保存用フルサイズの自動確認、容量バーによる比較、ダウンロードまでをブラウザ内で行えます。変換順序は、ソース向きの正規化、回転・反転、最終表示向きでのクロップ、リサイズ、エンコード／圧縮です。メタデータを保持・再注入せず、変換後のピクセルラスタをエクスポート元にします。

画像を選択すると、ブラウザの表示領域全体を使った暗色の編集画面になります。傾けた画像も全体を表示し、余白を含まない範囲で端まで切り抜けます。下部の「クロップ」「傾き・反転」で操作し、中央は編集と圧縮前後の比較を切り替えられます。比較は全体表示で、画像上を左右にドラッグして境界を動かせます。境界にフォーカスすると矢印キーでも調整できます。「出力設定」は初期状態で画像の手前に表示されます。メニュー右上のパネルアイコンで最小化・展開でき、展開時もパネルのサイズは変わりません。「保存」から確認済みの画像をダウンロードします。画質の設定値は容量の削減率ではなく、容量は実際の保存結果から計算します。

サーバーAPI、アカウント、データベース、バッチ処理、クラウド保存プリセット、目標KB自動最適化、HEIC、AVIF、GIF、アニメーションWebP、メタデータ保持はv1の対象外です。
