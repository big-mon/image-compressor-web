# image-compressor-web

ブラウザ内で画像をトリミング・圧縮する、独立した静的 React + TypeScript + Vite アプリです。

## Quick Start

```sh
pnpm install --frozen-lockfile
pnpm run dev
```

## 機能とスコープ

JPEG・PNG・WebPを選択し、比率指定付きのクロップ、90度回転、±45度の傾き補正、反転、リサイズ、形式・品質指定、Worker生成のクイックプレビュー、圧縮を開いている間の保存用フルサイズの自動確認、容量削減率の表示、ダウンロードまでをブラウザ内で行えます。変換順序は、ソース向きの正規化、回転・反転、最終表示向きでのクロップ、リサイズ、エンコード／圧縮です。メタデータを保持・再注入せず、変換後のピクセルラスタをエクスポート元にします。

画像選択前の画面は選択枠・フッター・折りたたみ説明を表示領域内に配置します。画像選択後は画面全体を画像の表示領域にし、操作メニューをその上に重ねます。初期倍率は100%（画像の1pxを1 CSS pxで表示）です。右上の現在倍率の左右にある「−」「＋」または画像上のスクロールで拡大縮小、Spaceとドラッグまたは中ボタンドラッグで表示位置を移動できます。表示倍率や位置は出力寸法に影響しません。下部中央の「クロップ」「傾き・反転」「圧縮」で操作を切り替えます。クロップは画像上で移動でき、四隅のハンドルから反対側の角を固定してサイズ変更できます。矢印キーでも移動・リサイズでき、Shiftで変更量を増やせます。三分割線と現在の出力プレビューを切り抜き範囲内に表示します。傾きで生じた余白は切り抜き範囲に含めません。「圧縮」を選ぶと切り抜き枠が消え、圧縮前後を画像上の境界のドラッグで見比べられます。境界は矢印キーでも調整できます。圧縮メニューには形式、画質、幅・高さを順に表示し、削減率の隣の「保存」からダウンロードします。画質の設定値は容量の削減率ではなく、容量は実際の保存結果から計算します。

サーバーAPI、アカウント、データベース、バッチ処理、クラウド保存プリセット、目標KB自動最適化、HEIC、AVIF、GIF、アニメーションWebP、メタデータ保持はv1の対象外です。
